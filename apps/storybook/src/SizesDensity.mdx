# Sizes and density

Comfortable is the default (matches the reference). Put `data-density="compact"` on any container – or wrap in `<DensityProvider density="compact">` – for dense screens. Table rows are 64px comfortable (two-line cells) and 40px compact. **Nothing interactive is smaller than 24×24** (WCAG 2.5.8).
